# Elf Rogue V6c production archive (prototype)

Read [the game handoff and tutorial](../../../../docs/ELF-ROGUE-V6C-HANDOFF.md) first.

`elf-rogue-weapon-fix.glb` is the reviewed runtime candidate: 19,958 triangles, 2,374,996 bytes, 18 joints, one 2048² atlas, eight canonical clips. SHA-256: `eed37e08843e810e046bb739fcff55417beeae56fdff1797fb010497350bab4b`.

`elf-rogue-weapon-fix.blend` is the editable generation scene with per-object actions. It is **not identical to the final merged GLB's clip organization**. A simple Blender export does not reproduce the merged result: merge script adds per-clip channel defaults to prevent equipment state leakage. For final animation inspection, import the final GLB into a fresh Blender scene or run `render-v6c.py`.

## Reproduce the V6c correction

Blender **4.3.2**, Python 3 stdlib. Scripts were made portable using `ECHO_ROGUE_WORKDIR`; original geometry/timing logic is unchanged. Input is the preserved V5 GLB (`inputs/`, SHA `8d9bea955193245116e898cb2b214fd1af55472ae21cd9b341d194fbde717b5e`), not a new Tripo generation. This is a reproducible **V5 → V6c** step, not a claim the entire historical V1–V5 pipeline is automated here.

From repository root:

```sh
bash output/characters/elf-rogue-v1/animation-v6c/scripts/rebuild.sh
```

Set `BLENDER=/path/to/blender` if needed. The wrapper prints a fresh work directory. It executes, in order:

1. `blender -b -t 4 --python scripts/weapon-fix-v6c.py` (eight per-clip GLBs and `.blend`).
2. `python3 scripts/merge-clips-v6c.py` (combined GLB and reset/default channels).
3. `python3 scripts/finalize-v6c.py` (texture deduplication and limitation metadata).

To verify/export previews, set `ECHO_ROGUE_WORKDIR` to that printed directory and run Blender with `--python` on `render-v6c.py` (fresh GLB import/eight clips), then `clearance-v6c.py`, `views-v6c.py`, `side-motion-v6c.py`. Views requires roundtrip blends produced by render. Python Pillow is needed for contact-sheet scripts where used; ffmpeg is needed to encode PNG sequences as 30fps H264 MP4. These are Blender/local renderer proofs, not screenshots of Tripo Studio or the live game.

Do not overwrite the archived candidate automatically. Compare GLB structure, bounds, visual poses and game transitions before accepting regenerated bytes. Blender/exporter variations can change binary hashes.

## Evidence and limitations

- `weapon-review.png`, side MP4s: actual final-GLB local Blender renders.
- `verification/game-captures/`: actual local Echoes Below World, no live save changes.
- JSON audits: measured bow plane, sampled collision/clearance and bounds.
- `manifest.json`: archive checksums and provenance. It is separate from the game's approved runtime manifest.

No individual finger bones, approximate draw fingers remain visibly open; rigid bow limbs; procedural gait/reactions; instant dagger equip/return. Licence plan/terms not verified. Not ready for public/commercial shipping. No production model replacement or deployment.
