## Fakta yang sudah diperiksa
- Gambar referensi: OpenAI imagegen. Model 3D: Tripo Studio P2.0 Smart Mesh, mode Quad.
- Target 750 polygon. Hasil aktual 898 polygon: 750 quad + 148 triangle, atau 83,5% quad.
- Ekspor GLB berisi 1.648 triangle, sekitar 843 KB, dan tekstur tertanam 2K.
- Biaya Tripo: geometri 100 + tekstur 2K 10 = 110 kredit. Tidak ada biaya tambahan ekspor yang teramati.
- Pedang sudah diekspor sebagai FBX dan GLB. Belum diuji pada tangan elf atau di game.
- Smart UV tidak dijalankan secara terpisah. Jangan menyebut hasil 100% quad, game-ready, atau mengklaim benchmark kecepatan.
