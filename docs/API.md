# Implemented client contract

Import interfaces from `shared/types.ts`. Server port 4317, Vite proxy `/api` to `http://127.0.0.1:4317`. All endpoints JSON except audio. `GET /api/health` returns `{ok:true,aiConfigured:boolean}`. `GET /api/session` returns `{csrfToken}`. Send that token as `x-csrf-token` on every POST. Token is process-local, reacquire on 403 after server restart. Local Host and Origin only.

- `POST /api/saves` body `CreateSaveRequest` returns **PublicSave directly**. Appearance IDs ember/moss/moon. Class guardian/scout/adept; background delver/envoy/survivor.
- `GET /api/saves` returns `{saves:[{id,name,sceneTitle,mode,updatedAt}]}` newest first.
- `GET /api/saves/:id` returns PublicSave directly. `scene.id` is approach/hall/cookfire/prison/bell/aftermath. Party IDs hero/mira/oren. Enemies only appear during current combat. All actions are contextual, valid choices and include exact opaque `id`, label, description, kind and optional targetId/actorId/check/dangerous. Render these, do not fabricate IDs.
- `POST /api/saves/:id/actions` body `{commandId:crypto.randomUUID(),expectedRevision:save.revision,actionId:option.id}` returns updated PublicSave. The UI should confirm the option's description before sending. This synchronous command completes rolls and auto companion/enemy turns and persists atomically. Reuse identical commandId/body on network retry, never a fresh command ID. 409 means stale revision: reload. 422 means illegal action. Rules logs contain exact dice; AI is separate and never required for game progress.
- Optional stricter preview: `POST /api/actions/preview` body `{saveId,expectedRevision,actionId}` or `{saveId,expectedRevision,text}` returns Preview. Text is mapped by AI to currently legal action IDs, or rejected 422. Preview never mutates or rolls. `POST /api/actions/commit` body `{previewId,commandId}` returns PublicSave. Expires after 2 minutes.
- `POST /api/saves/:id/dialogue` body `{speaker:'mira'|'oren'|'dm',text:string}` returns Dialogue. Max 1000 chars. Truly generated AI dialogue; failure is 503/429, show an honest unavailable state. Only public knowledge is given to model. Can ask Mira/Oren about the current situation; dm can narrate confirmed scene/results. No world mutations.
- `GET /api/saves/:id/dialogues` returns `{history:[{id,speaker,playerText,replyText,createdAt}]}`: at most 50 persisted exchanges, oldest first, for journal reload. `GET /api/saves/:id/dialogue?speaker=mira` returns the latest six exchanges scoped to that speaker. Both sides of a successful exchange are saved atomically and the six recent speaker-scoped exchanges accompany subsequent AI calls, clearly separated from confirmed world facts. Older pre-fix AI replies are preserved with an empty `playerText`; the missing original utterance is never fabricated.
- `POST /api/narrations/:id/audio` body `{}` returns `{url:'/api/audio/...'}`. ID comes from Dialogue. Voice is generated from stored text only. `GET url` returns cached MPEG audio. AI-generated voices disclosure required. Replay same URL is free.
- `POST /api/transcriptions` body `{saveId,audioBase64,mimeType,durationSeconds}` returns `{text}`. Max30 seconds,10MB; mimeType audio/webm, audio/mp4, audio/wav, audio/ogg. Browser records push-to-talk then presents editable transcript, never auto-commits.
- `GET /api/usage?saveId=...` returns `{campaignUsd,hourUsd,limits:{campaignUsd:25,hourUsd:2},warning:boolean}`; conservative reservations include uncertain failures.

`AI_HOURLY_LIMIT_USD` and `AI_CAMPAIGN_LIMIT_USD` set positive spending limits at server startup. Smaller positive values apply; values above the authorized ceilings are clamped to $2/hour and $25/campaign. Empty, malformed, non-finite or nonpositive values use those defaults. The usage endpoint exposes the effective limits and warns at 60% of the campaign limit. Checkpoint branches share campaign accounting.
- `POST /api/saves/:id/checkpoints/:checkpointId/restore` body `{}` returns a **new** PublicSave branch, preserves original. Available checkpoint IDs/labels in PublicSave.

Combat UI: server stops at the hero's turn, or waits at a downed hero until `continue` advances allies. Action choices include attack targets in reach, move anchors, guard, aim/heal according to class, potion, run and end turn. Movement and action are independent; End turn runs other actors in initiative order until next hero turn. With AI configured, End turn/Continue asks Luna separately for each companion's choice from a legal action list, then revalidates the revision and applies valid choices through rules. Stale targets fall back to legal tactics. Provider failures are explicitly logged and deterministic protective tactics keep play possible. The initial combat entry uses deterministic initiative-order tactics; later rounds use AI decisions. No background processing between requests. End turn can take several seconds while two bounded AI calls complete; show a planning state and preserve command ID for retries.

Every gameplay outcome has `logs` with authored/rules/ai source. Show most recent logs, dice and current state. Scene authored descriptions are always available without AI. `mode=complete` is a real slice ending; `defeat` offers checkpoint restore. Autosave occurs after each successful action. No separate save call is needed. Creation and optional AI calls are separate requests from idempotent gameplay actions.

Combat retreat: `regroup` asks companions to use up to their normal 6m movement toward the entrance and Guard on their turns. Move the hero to `move:exit`, then End turn/Continue as needed. `retreat` becomes legal once all standing members are in the exit zone; downed members are recovered on withdrawal. `cancel_regroup` restores normal tactics. Regroup turns skip paid AI planning because the player already supplied the party intent.

Targeted exploration interactions now update authoritative party positions. The acting standing character approaches roughly 1.2m short of the entity, companions follow at reserved offsets, and the unresolved hall plate keeps every approach on its safe side. Authored scene changes reset entry positions; the client should interpolate only within the same scene. These are room interaction anchors, not unrestricted navigation. Hero-only persuasion, distraction, lock picking and boss negotiation require a standing hero; companion healing and party travel remain available when the hero is downed.

Error JSON `{error:code,message:string,currentRevision?:number}`. Never treat AI failure as gameplay failure or automatically repeat a committed command. API has no SSE; presentation animates snapshot changes. No full 24-hour campaign is claimed.
